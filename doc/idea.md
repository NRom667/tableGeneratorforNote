# 目標
noteに貼り付けられる表を簡単に作ることができるwebサイトを作る
webサイトには広告を貼り、マネタイズを目指す

# 課題
noteには通常の表(table)を簡単に挿入することができない。
KaTeXを使った書き方であれば挿入できるようである。
そこで、簡単に表を作れるwebサイトを作る。

# 機能概要
markdown, Excel, スプレッドシートからコピーして貼り付けると、KaTeX形式のコードと出来上がりプレビューが出力される。そのコードをコピーしてnoteに貼り付ける想定。
表のStyleはとりあえずは1種類固定とするが、将来的にはボタン等でいくつかのStyleを切り替え可能とする。

# 機能詳細
- Markdown表、およびExcel・Googleスプレッドシートからコピーしたタブ区切りテキストに対応する。書式、セル結合、画像、数式情報は引き継がず、表示文字列のみを変換する。
- セルの値は原則として \text{...} に入れ、KaTeX用にエスケープする
- 生成結果の参考プレビューを表示する。note上の表示と完全に一致することは保証しないが、なるべく近づける。
- データ貼り付け直後に自動変換する
- データ貼り付け欄を直接編集も可能
- 変換した表側の直接編集はMVPでは不可とするが、将来的には検討する
- 出力結果のコピーボタンと、コピー完了時に成功表示を出す
- Styleは標準では罫線あり、中央ぞろえとする
- 行数や列数は制限しない。note側でスクロール可能な表示にしてくれるため
- 「貼り付けた内容はブラウザ内で処理され、サーバーには送信されません。」の文言を書く。

# デザイン
noteのように、シンプルでミニマル、フラットなデザインを目指す。
メインカラーは緑を使用する。(Excelが緑基調なので、同じイメージ)
